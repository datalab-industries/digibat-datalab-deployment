# DIGIBAT Discovery Benchmark

This directory contains code for ingesting the DIGIBAT Discovery Benchmark dataset into *datalab*.

It expects to find the dataset in a subdirectory `./data`, containing the Excel spreadsheet summary and all raw data files.

Authenticated users can access the dataset directly on the DIGIBAT *datalab* at [https://digibat.dept.ic.ac.uk/collections/Discovery-Benchmark](digibat.dept.ic.ac.uk/collections/Discovery-Benchmark).
